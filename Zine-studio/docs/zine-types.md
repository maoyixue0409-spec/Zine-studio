# Zine Types

## 旅行相册 Travel Album

适合记录旅行路线、城市观察、照片、票据、食物和地点体验。

## 粉丝制品 Fan Zine

适合整理人物、作品、舞台、名场面、应援语和粉丝社群记忆。

## 文创产品 Cultural Creative Product

适合展示文化来源、产品故事、包装、材质、使用场景和品牌表达。

## IP 设定集 IP Guidebook

适合整理原创世界观、角色、场景、道具、符号系统和衍生设计规则。

## 摄影集 Photography Zine

适合组织照片顺序、图注、摄影师陈述、影像节奏和作品集叙事。

## 个人记录 Personal Journal

适合整理记忆、日常片段、时间线、照片、票据、收藏物和文字记录。
