# Privacy

Zine Studio is a static browser-based tool.

## What Stays Local

- Material images uploaded by the user.
- Style reference images uploaded by the user.
- Extracted color palettes.
- Generated prompt text.

## What Is Not Collected

Zine Studio does not collect, store, upload, or transmit user files.

There is no backend, database, analytics script, account system, or API connection in this version.

## Important Note

If you copy generated prompts into an external AI tool, that external tool's privacy policy applies.
