# GitHub Upload Checklist

Use this checklist before publishing.

- [ ] `index.html` opens in the browser.
- [ ] `src/app.js`, `src/data.js`, and `src/style.css` exist.
- [ ] `README.md` explains what the project does.
- [ ] `LICENSE` exists and uses MIT.
- [ ] `.gitignore` exists.
- [ ] `PRIVACY.md` explains local image handling.
- [ ] `CONTRIBUTING.md` explains how others can help.
- [ ] The repository does not include private reference images.
- [ ] GitHub Pages is enabled after upload.
