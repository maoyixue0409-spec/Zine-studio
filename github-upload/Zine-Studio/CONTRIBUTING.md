# Contributing

Thank you for helping improve Zine Studio.

## Good First Contributions

- Improve README wording.
- Add clearer prompt templates.
- Improve mobile layout.
- Add more Zine type options.
- Add export to `.txt` or `.md`.
- Improve accessibility labels.

## Local Development

Open `index.html` directly, or run:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Pull Request Checklist

- The page still opens from `index.html`.
- No backend or API is required.
- Uploaded images stay local in the browser.
- Mobile layout remains usable.
- README is updated if behavior changes.

## Project Direction

Zine Studio is a product project for creators and communities. It is not a personal blog, photography portfolio, or personal brand website.
