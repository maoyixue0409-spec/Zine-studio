# Zine-studio
Zine Studio 是一个开源的 AI Zine 制作工具。它可以帮助普通创作者快速生成适合旅行相册、粉丝制品、文创产品、IP 设定集、摄影集、个人成长记录等场景的 Zine 制作 Prompt。

中文 | English

Zine Studio is an open-source AI prompt generator for creating personal Zines.

Zine Studio 是一个开源的 AI Zine 制作工具。它可以帮助普通创作者快速生成适合旅行相册、粉丝制品、文创产品、IP 设定集、摄影集、个人成长记录等场景的 Zine 制作 Prompt。

You can use the generated prompt in ChatGPT, Claude, Gemini, Doubao, Tongyi Qianwen, or any other AI tool.

⸻

What is a Zine?

A Zine is a small self-published booklet. It can be personal, experimental, artistic, fan-made, or commercial.

Zine 是一种小型自出版作品，可以是一本小册子、折页、摄影集、旅行记录、粉丝刊物、文创手册或 IP 设定集。

How to Use

Option 1: Use the Web Page

1. Open index.html.
2. Choose your Zine type.
3. Choose your design style.
4. Fill in your topic, materials, audience, page count, mood, and extra requirements.
5. Click Generate Prompt.
6. Copy the generated prompt.
7. Paste it into any AI tool.

⸻

Option 2: Use the Prompt Templates

Go to the prompts/ folder and choose a template.

For example:

prompts/travel-zine.md
prompts/fan-zine.md
prompts/ip-zine.md

Copy the template and edit it based on your own project.

Example Use Cases

Travel Album

Create a Zine for a trip to Chengdu, including photos, routes, food notes, emotional memories, and a printable booklet structure.

Fan Zine

Create a fan-made Zine for an idol, anime character, game character, or fandom event.

Cultural Creative Product

Create a product concept Zine for postcards, stickers, notebooks, city souvenirs, or museum-inspired products.

IP Guidebook

Create a Zine for an original character, worldbuilding, story setting, visual identity, and product extension.

Photography Zine

Create a photography booklet with visual sequencing, captions, layout ideas, and editorial-style storytelling.

Personal Growth Journal

Create a personal Zine about life stages, emotions, memories, choices, and self-growth.
